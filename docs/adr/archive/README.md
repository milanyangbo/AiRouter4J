# ADR 归档（第 1 版，2026-10-23 ~ 2026-10-24）

这一批 ADR 于 **2026-10-25 整体重写**（第 2 版），又于 **2026-10-26 再次整体重写**（第 3 版，现行）。
现行版在上级目录 [`../`](../)。旧版保留在此，用于追溯「当初为什么这么定」，**不再作为权威**：
与现行版冲突时以现行版为准。

## 第 2 版去哪了

第 2 版（2026-10-25，13 篇）**没有归档在此**，它已随阶段 0 的清空一并删除。
取回方式：`git show baseline-pre-11:docs/adr/0001-project-scope-and-lineage.md`
（目录下全部 13 篇同理，`git ls-tree -r baseline-pre-11 docs/adr/` 可列名）。

它作废的原因不是写错，而是前提再次变了：决定从「保留已实现代码、增量补齐」
改为「清空实现、按功能重排」，于是它大量「本阶段实现了什么」的叙述全部失效。

## 为什么要整体重写

第 1 版全部写在同一个前提下：**骨架能不能立住还不知道**。因此它们的核心结论是收敛
（「不追求功能对等」、「先验证再铺开」）。

票 01–09 交付后这个未知项消失了：一个 Face、两种 wire 形态、熔断与结算闭环、契约测试与结构规则
都已落地并被 120 个测试背书。目标态随之从「验证骨架」变成「按 legacy 能力面补齐」。

前提变了，写在前提上的结论就不能只做增量修订 —— 增量修订会留下一批「内容正确但前提已失效」的文档，
读的人要自己判断哪句还作数。所以是重写，不是追加。
