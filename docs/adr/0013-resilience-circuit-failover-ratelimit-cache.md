# ADR-0013：韧性（熔断 / 失败转移 / 限流 / 响应缓存）

- 状态：已接受
- 日期：2026-10-26
- 相关：[0005](./0005-streaming-terminal-outcome-contract.md)（Outcome 是唯一输入）、[0014](./0014-quota-multi-window-ledger.md)

能力面：**第 4 类（韧性）**

## 1. 熔断

| 决定 | 内容 |
|---|---|
| 粒度 | **实例级**（不是服务级 —— 一个实例挂了不该拖垮整个服务） |
| 输入 | **只消费 `Outcome`**。看不到状态码，看不到异常类型（R4 / R9 判红） |
| 状态 | `CLOSED` → `OPEN` → `HALF_OPEN` → `CLOSED`，`AtomicReference + CAS` 无锁更新，带版本号 |
| 半开 | `OPEN` 冷却结束之后被**读成** `HALF_OPEN`：「可以再试一次」是时间推出来的事实，不需要先发一次请求来触发 |
| 留痕 | 状态迁移记录里带着触发它的那个 `requestId` —— 排查时有用的是「谁把它打开的」 |
| 不计入 | `CLIENT_CANCELLED` 不计入熔断（用户关页面不该熔断健康实例） |

> legacy 的 `LockFreeCircuitBreaker` 可搬：无锁状态机是它少数经过验证的部分。
> 要改的是它读状态码与异常的那部分 —— 换成只读 `Outcome`。

## 2. 失败转移

**(a) 只对显式白名单内的可重试失败生效。** 白名单必须写出来并被断言：

| 可重试 | 不可重试 |
|---|---|
| 连接失败、超时、`UPSTREAM_TIMEOUT` | 400 / 401 / 403 / 404（语义错误，换个实例还是错） |
| 429、5xx | 认证失败、配额耗尽、本地拒绝 |

> 写成「除了取消都重试」等于把 4xx 也重试一遍，于是「模型名写错」会变成一个要打满所有实例才返回的错误。

**(b) 不重试到同一实例**，次数有上限（默认 1 次换实例）。

**(c) 只结算最终那一次。** 中间尝试计入指标（重试次数、换过哪些实例），
但不重复扣配额、不重复写调用历史主记录。
> 术语表里 failover 与 retry 分开，正是为了让「重试算几次结算」有答案。

## 3. 限流

**(a) 四个算法插在同一个端口下**：`TokenBucket` / `SlidingWindow` / `LeakyBucket` / `WarmUp`。

**(b) 作用域四级**：`global` / `service` / `instance` / `client`（`client` 即**租户**）。
**实例维度以 [0010](./0010-configuration-model-and-runtime-registry.md) 为前提** —— 在那之前做限流，做出来的是一个全局开关。

**(c) 后端两级**：Redis 原子 Lua → 本地降级窗口（有额度上限、有 TTL）。

**(d) 管理面限流不是另一套。**
legacy 的业务限流与管理面限流（走 WebFilter）**两套并存、零共享**，配置、算法、指标各一份。
新版：同一内核的另一条入口，作用域是管理面路径 / 管理员。

**(e) 限流的判定挂在可用性那一道闸上**（选择链第 ③ 步），与熔断由同一条管道消费，
判不过的请求在本地结束 —— **不出网，也不结算**。

**(f) 默认 fail-closed**：限流器自己挂了应当拒绝而非放行。

## 4. 响应缓存

| 决定 | 内容 |
|---|---|
| 开关 | **默认关闭**（opt-in）。legacy 的 `jairouter.response-cache.enabled=false` 也是默认关闭，这个默认值是对的 |
| 只对**确定性请求** | 温度归零、无工具调用、请求体一致。非确定性请求缓存 = 返回别人的答案 |
| 键必须含**租户** | 否则跨租户串数据 —— 这是最贵的一类数据泄露 |
| 只缓存**非流式** | 流式缓存要求先攒完整响应，与流式的目的相反 |
| TTL | 默认 1 小时，可配 |

## 5. 裁决

| legacy 的东西 | 裁决 |
|---|---|
| `LockFreeCircuitBreaker` | **改**（搬状态机，换成只读 `Outcome`） |
| 4 个限流算法 | **搬**（改：作用域加实例级、后端统一、管理面并入） |
| 限流 Lua 脚本 | **搬**（改：合并两套为一套键空间） |
| 管理面 WebFilter 限流 | **不搬**（作为独立机制消失，变成同一内核的入口） |
| `ResponseCacheProperties` 的默认值 | **搬**（默认关闭、TTL 1h） |

## 6. 验收

- 熔断：三次失败后实例不再被选中；冷却结束后被读到 `HALF_OPEN`；成功的探测关闭电路
- 熔断留痕：状态迁移记录可查到触发它的 `requestId`
- 失败转移：不可重试的 4xx **不换实例**（有断言）；可重试的换实例且不重复结算
- 限流：四个算法在同一端口下可插拔；Redis 不在时走本地降级且**行为被断言**（不是放行）
- 缓存：跨租户同请求不串数据；非确定性请求不进缓存；关闭时零开销
- 取消不计入熔断
