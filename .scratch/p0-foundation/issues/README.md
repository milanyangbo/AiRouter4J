## 每票的固定动作

1. 开工前打基线 tag：`git tag baseline-pre-<票号> && git push origin baseline-pre-<票号>`
2. 实现 + 测试
3. **反向验证**：故意破坏一处，确认断言真的会红，然后还原
4. 回填文档（ADR / GLOSSARY / AGENTS.md / 票本身勾选）
5. 提交并推送 `rewrite/p0`
