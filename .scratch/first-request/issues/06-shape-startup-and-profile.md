# 06: 形态自述、启动期校验与档位

**What to build:** 形态自己回答三个问题；地址配错则应用**起不来**并指名具体值；
`local` 档位不配任何端点变量也能起来并完成一次调用。

「配错了起不来」是它独立可验证的行为 —— 不是「配置文档里写着必须以 `/v1` 结尾」。

**Blocked by:** 02

**Status:** ready-for-agent

## Acceptance criteria

- [ ] `UpstreamShape` 自述三件事：地址该长什么样、这个协议要不要凭证、
      流怎么结束（经由各自的分帧器）
- [ ] 地址形态是**启动期校验**而不是约定：`openai` 形态的端点必须以 `/v1` 结尾
      且不带尾斜杠；违反则启动失败并**指名具体值**
- [ ] 形态由配置**显式**给出，不允许按地址猜 ——
      同一台本机 Ollama 上 `/v1` 与 `/api` 两种地址都在，猜必然猜错
- [ ] 凭证只在形态需要它时才必填（`openai` 形态需要）
- [ ] `local` 档位在**无网络**环境下能起来并完成一次受支持的调用
- [ ] 档位切换只改 profile 或环境变量，**不改代码**
- [ ] baseUrl 与凭证只从环境变量读取，配置文件里只能是占位符
- [ ] 有一条测试断言受跟踪文件里不含真实凭证
- [ ] 措辞（错误文案与「什么算异常结束」的解释）由形态自己提供，
      **不写在共享的错误映射里** —— 历史上为了改一处文案动了共享映射，
      结果另一个形态的 golden 基线一起变红
- [ ] 本机地址一律写 `127.0.0.1` 不写 `localhost`

## Notes

- 本阶段只落地 **`openai` 一种形态**、SSE 一种分帧。
  `ollama` 形态与其逐行 JSON（NDJSON）分帧不在本阶段（见 ADR-0020 阶段 12）
- 测试文件并入模块预算，需合并同类项
